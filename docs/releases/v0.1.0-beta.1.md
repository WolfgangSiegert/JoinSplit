# JoinSplit v0.1.0-beta.1

JoinSplit is now available as a public, clearly labelled beta showcase at
[joinsplit.tiny-bits.org](https://joinsplit.tiny-bits.org).

## Included

- browser-local Groups, Participants, Expenses and Settlements
- deterministic Equal Split, balances and settlement proposals
- IndexedDB persistence with queued synchronization to Laravel and PostgreSQL
- statement snapshots, archive/reactivation and local reset
- mobile-first interface, dark mode and accessible navigation
- automated unit, integration, browser and accessibility checks

## Beta boundary

Use only fictional, non-sensitive test data. Access is bound to one browser
installation, there are no user accounts or credential recovery, and the
server copy is not a supported backup. The free hosting tier can introduce cold
starts.

This release passed the reduced M4 beta-showcase gate. The full manual
real-browser/device matrix, a manually forced offline/reconnect run, cold-start
measurement, alert-delivery verification and a fresh Neon capacity review are
deferred until Production-Readiness work.
